## Proyectos
- Desarrollo de aplicación móvil: SeaShell Calculator.
Es una calculadora química con varias funciones tales como: cálculo de unidades de concentración 
(físicas y químicas), lista de masas molares, balanceador de ecuaciones químicas y tabla periódica.
Cuenta con el desarrollo de una API REST para manejo de base de datos, seguridad (autenticación y
autorización), validaciones, control de datos, manejo de solicitudes HTTP.
Además, el desarrollo de la aplicación cuenta con el uso de la tecnología Jetpack Compose en
integración con Kotlin más el consumo de la API y la construcción del entorno de base de datos
dentro de la aplicación.
- Desarrollo de sitio web: FormCorp.
Es un sistema web que permite a usuarios poder realizar consultorías, así como llevar un control
del proceso de obtención de permisos y cumplimiento de requerimientos para abrir un restaurante.
Cuenta con el desarrollo de una API REST implementada con JavaScript, servidor en Node.js itegrado
con Express. Implementa el manejo de la base de datos, seguridad (autenticación y autorización),
validaciones, control de datos, manejo de solicitudes HTTP.
Además, el desarrollo del frontend implementa el uso de la tecnología Vite integrado con el 
framework React más el consumo de la API.
